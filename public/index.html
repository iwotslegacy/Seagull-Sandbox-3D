How to play

Desktop and mobile controls are both supported. Mouse lock works on PC; drag-look works on touch devices.

Run the server.
Open the project in VS Code and run npm start.
Open the site.
Visit http://localhost:3000. For another device, use your computer’s local IP address.
Create or join.
Use the website lobby or pause menu. Share the room code with other players.
Mess around.
WASD to move, mouse to look, E to grab/drop, left click to eat, P to poop.
